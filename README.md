# MPHC zone map · April 2027 CJ-II vacancies

Interactive Madhya Pradesh map with Transfer Guidelines 2022 zones (Gwalior / Indore / Jabalpur / Rewa), tenure-due CJ-II courts, and aerial km from Mandsaur and Bhopal.

## Live page

- **Instant preview:** https://htmlpreview.github.io/?https://github.com/devesh096/mphc-zone-map/blob/main/index.html
- **jsDelivr:** https://cdn.jsdelivr.net/gh/devesh096/mphc-zone-map@main/index.html
- **raw.githack:** https://raw.githack.com/devesh096/mphc-zone-map/main/index.html
- **GitHub Pages** (after one Settings click): https://devesh096.github.io/mphc-zone-map/

To turn on GitHub Pages: repo **Settings → Pages → Deploy from a branch → main / root → Save**.

## Notes

- Distances are aerial kilometres, not road km.
- Vacancy list is a tenure projection from the official CJ-II gradation list dated 06-09-2026, not the signed 2027 transfer order.
